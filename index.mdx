The **Raiz do Bem API** is the transactional backbone of the Raiz do Bem platform — a social-impact project developed in partnership with the **Turma do Bem** NGO, the world's largest specialized dental volunteer network. The API centralizes the management of aid requests, beneficiaries, volunteer dentists, dental appointments, and social programs through a secure, scalable RESTful interface.

## What the API does

The Raiz do Bem API orchestrates the full lifecycle of dental care delivery for people in social vulnerability:

<CardGroup cols={2}>
  <Card title="Aid Request Triage" icon="clipboard-check" href="/api/pedidos-ajuda">
    Accept public aid requests, run eligibility checks, and approve or reject them through a controlled workflow.
  </Card>
  <Card title="Beneficiary Management" icon="users" href="/api/beneficiarios">
    Convert approved requests into active beneficiaries linked to specific social programs.
  </Card>
  <Card title="Volunteer Dentist Network" icon="tooth" href="/api/dentistas">
    Register and manage volunteer dentists with specialties, availability, and geolocation.
  </Card>
  <Card title="Geographic Appointment Matching" icon="map-pin" href="/concepts/geographic-match">
    Automatically pair beneficiaries with the nearest available dentist using the Google Maps Routes API.
  </Card>
</CardGroup>

## Getting started

<Steps>
  <Step title="Configure environment variables">
    Set `DB_URL`, `DB_USUARIO`, `DB_SENHA`, and `GOOGLE_API_KEY` before starting the server.
  </Step>
  <Step title="Start in dev mode">
    Run `./mvnw quarkus:dev` to launch the API with live reload at `http://localhost:8080`.
  </Step>
  <Step title="Obtain a JWT token">
    `POST /auth/tokenAcesso` with your collaborator credentials to receive an `accessToken`.
  </Step>
  <Step title="Call a protected endpoint">
    Add `Authorization: Bearer <accessToken>` to list beneficiaries via `GET /beneficiario`.
  </Step>
</Steps>

<Note>
  The Swagger UI is available at `http://localhost:8080/q/swagger-ui/` when running in dev mode, providing interactive documentation for all public endpoints.
</Note>
